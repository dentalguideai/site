DentalGuide AI

AI-powered guidance for common dental symptoms

DentalGuide AI is a personal project designed to help users better understand common symptoms after dental treatments and identify when professional evaluation may be needed.

What is DentalGuide AI?

The system provides general educational guidance based on symptom type, severity, and time since treatment. It focuses on common situations following treatments such as tooth extractions, root canals, fillings, aligners, and cleanings.

Symptom-Based Logic

Evaluates user input according to symptom severity and treatment context.

AI-Powered Guidance

Provides structured educational recommendations and next-step guidance.

Interactive Web App

Built as an accessible web application and deployed online for live use.

DentalGuide AI provides general educational information only and does not replace professional dental diagnosis, treatment, or emergency medical care.
